# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Security analysts, vulnerability-management teams and infrastructure engineers investigating a local environment.

## Product Purpose

RiskScope is an asset-aware vulnerability exposure and risk prioritization workstation. Its central workflow connects inventory and SBOM imports to evidence-backed correlation, contextual risk, potential paths, remediation, verification and reports.

## Positioning

Observations, deterministic automated assessments and attributed analyst judgments are separate, inspectable records. A vulnerability's global severity is not its environmental priority.

## Operating Context

A local browser workstation with SQLite persistence, offline feeds and synthetic ExampleCorp fixtures. No scanning, exploitation, patch deployment, cloud service or LLM dependency.

## Capabilities and Constraints

The authoritative implementation brief is preserved in `docs/implementation-specification.txt`. All 81 sections apply. Unknown intelligence remains unknown. Synthetic advisories are not factual claims about any real product. External integrations are optional and disabled.

## Brand Commitments

RiskScope. Precise, accessible, scan-friendly analyst language; no hype or unsupported security claims.

## Evidence on Hand

User-supplied specification and deliberately synthetic fixtures only. No real customer or organizational data.

## Product Principles

- Preserve provenance and history.
- Explain each automated decision.
- Never confuse installed software with demonstrated exploitability.
- Remain useful entirely offline.

## Accessibility & Inclusion

Keyboard-operable, labeled controls, visible focus, responsive layouts and explicit loading, empty and error states.

## Implementation Assumptions

The user explicitly authorized proceeding autonomously. The first implementation uses an English-language, single-user, loopback-only web workstation and a restrained evidence-led interface. Authentication and multi-user hosting are outside this local execution scope.
